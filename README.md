### About the Experiment

X-Ray Diffraction (XRD) is a powerful analytical technique used to determine the crystal structure of materials. This simulator provides an interactive platform to understand how XRD works and how to determine lattice parameters of crystalline materials. Students can select different specimens, adjust scanning parameters like voltage, current, angle range, and step size, and observe the resulting diffraction patterns.
