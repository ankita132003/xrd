### About the Experiment

X-Ray Diffraction (XRD) is a powerful analytical technique used to determine the crystal structure of materials. This simulator provides an interactive platform to understand how XRD works and how to determine lattice parameters of crystalline materials. 

**Key Features:**
- Select different crystalline specimens (Aluminium, Glass, Paper, Sand, Silicon Powder)
- Adjust scanning parameters: voltage, current, angle range, and step size
- Observe real-time diffraction patterns
- Analyze crystallographic data for FCC and BCC structures
- Learn fundamental principles of X-ray crystallography

### How to Use

1. **Start the Simulator**: Click ON button to power up the XRD machine
2. **Select Specimen**: Choose from available crystalline materials
3. **Open Doors**: Click OPEN to access the specimen chamber
4. **Configure Settings**: Set voltage, current, start angle, end angle, and scan rate
5. **Run Scan**: Click START SCAN to initiate X-ray diffraction measurement
6. **Analyze Results**: View the diffraction pattern and crystallographic data
7. **Save Data**: Download the diffractogram for further analysis
